# Para Marcela — 18 anos

Cartão virtual de aniversário de Israel para sua afilhada Marcela.

**Abrir o cartão:** https://israelflemos.github.io/marcela-18-anos/

No celular, toque em **Tocar para abrir** e use os botões ou deslize para ler as sete mensagens. No computador, também funcionam as setas do teclado. O botão **Ler novamente** aparece ao final.

A página é um único arquivo `index.html`, sem cadastro, cookies, rastreamento ou dependências externas. O repositório e o endereço do GitHub Pages são públicos; a marcação `noindex` apenas pede aos buscadores que não indexem a página, sem limitar o acesso de quem tem o link.
